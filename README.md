One sentence. One ridiculous invention. Zero lost socks left unmourned.

`main.py` (pure Python standard library, `os` only) writes exactly one
sentence — at most 220 characters — pitching the SockMatch 3000, a clip-on
scanner that sniffs your laundry pile, pairs every lonely sock with its mate
in under a second, and texts you a short eulogy for the ones it declares
officially lost.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same sentence, byte for byte, on every run.
